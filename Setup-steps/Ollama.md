## Ollama
Ollama is an open-source software that will let me download, manage and run LLMs from my machine locally. Every lab needs an LLM to attack, and Ollama is what will run that LLM on our own machine.
We will use a local API to send prompts through and then get the response back. By using Ollama, we keep the LLMs we use free and local so we don't need to worry about TOS violations, and we retain the ability to see
the weakness directly and have reproducible results.

# Install
Installation for this is, yet again, pretty straightforward. Simply visit the download site and download for your machine, then you don't need to make an account because everything will be local anyways. Just wait for
